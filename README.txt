วิธีเปิดใน Visual Studio Code
1) แตกไฟล์ zip ก่อน (คลิกขวา > Extract All)
2) เปิด VS Code > File > Open Folder... > เลือกโฟลเดอร์ cod-top10
3) ติดตั้งส่วนเสริม "Live Server" (Ritwick Dey) จากแท็บ Extensions
4) คลิกขวาที่ index.html > Open with Live Server
ไฟล์รูป rank-1.jpg ถึง rank-10.jpg ต้องอยู่โฟลเดอร์เดียวกับ index.html
